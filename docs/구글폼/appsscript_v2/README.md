## 🚀 배포 절차

### 1단계. Apps Script 프로젝트 생성

1. [https://script.google.com](https://script.google.com) 접속
2. `+ 새 프로젝트` 클릭
3. 프로젝트명: `설문시스템_v2`

### 2단계. 파일 업로드

Apps Script 편집기에 11개 `.gs` 파일을 각각 추가:

- 좌측 `파일` → `+` → `스크립트` 선택 → 파일명 입력
- 각 파일의 내용을 복사·붙여넣기

**⚠ 주의**: 파일명에 `.gs` 확장자는 자동으로 붙음. `config`, `introSection` 등 기본명만 입력.

### 3단계. 권한 승인

최초 실행 시 권한 요청이 발생합니다:
- `FormApp` — 구글폼 생성·편집
- `SpreadsheetApp` — 응답 스프레드시트 생성
- `DriveApp` — 파일 이동·권한

`고급 → 안전하지 않은 페이지로 이동 → 허용` 순서로 승인.

### 4단계. 검증 테스트

Apps Script 편집기 상단에서:

```
함수 선택: test_validateInstitutions → 실행
```

로그에 `✅ 기관 개수: 59개 일치` 등이 출력되면 정상.

```
함수 선택: test_createJ17Only → 실행
```

J17 단일 폼 1개가 생성되어 드라이브에 저장됩니다.
폼 URL로 접속해 문항이 정상 표시되는지 확인 후, **테스트 폼은 드라이브에서 수동 삭제**.

### 5단계. 전체 폼 일괄 생성

```
함수 선택: createAllForms → 실행
```

- 약 2~4분 소요 (Apps Script 실행 제한 6분 내)
- 중도 실패 시 `createSingleForm('J07')` 형태로 개별 재시도

### 6단계. 마스터 로그 확인

실행 완료 후 드라이브 최상위에 `설문시스템_v2_폼_마스터로그` 스프레드시트 생성됨.
여기에 17종 폼 ID·편집URL·응답URL·응답 스프레드시트 ID 기록.

## ⚠ 중요 주의사항

### 1. 척도 방향 (Claude Code 분석 시 필수 인지)

구글폼 `setScaleItem`은 min이 반드시 낮은 숫자이므로, 설문지의 "① 매우 만족 ~ ⑤ 매우 불만족" 순서를 구글폼에선 **뒤집어 설정**했습니다.

| 점수 | 동의형 척도 (공통-1·2·3, 특화 척도) | 만족형 척도 (공통-4) |
|---|---|---|
| 1 | 매우 그렇지 않다 | 매우 불만족 |
| 5 | 매우 그렇다 | 매우 만족 |

**→ CSV 분석 시 1=부정, 5=긍정으로 통일 처리**. 지시문 06에 명시 필요.

### 2. 헤더 매핑 시트 활용

각 응답 스프레드시트의 2번째 탭 `header_mapping`에 다음 형식으로 매핑 기록됨:

| 구글폼 문항 타이틀 | 내부 코드 |
|---|---|
| 귀하의 소속 기관은? | 도입-0 |
| 이번 참여하신 회차/일정은? | 도입-0-a |
| [공통-1] ... | 공통-1 |

**Claude Code의 CSV 파싱 로직**: 구글폼 응답 시트의 헤더명 → `header_mapping` 참조 → 내부 코드 변환 → `responses` 테이블 저장.

### 3. 권역 문항 삭제 — 기관 마스터로 자동 도출

설문에는 권역 문항이 없습니다. 응답 저장 시 `institution_name` → `institutions` 테이블 조회 → `region` 컬럼 자동 채움.

### 4. 기존 폼과의 관계

**권장**: 기존 17종(v1) 폼은 **응답 CSV 백업 후 드라이브에서 별도 폴더로 이동·보관**. 신규 v2 폼을 배포.

v1·v2는 문항 구조가 다르므로 **동시 운영 금지**. 수행기관에 v2 URL만 안내.

### 5. 수행기관 배포

마스터 로그에서 각 폼의 `publishedUrl`(응답 URL) 복사 → 수행기관별 안내.

추천 안내 문구:
```
[안내] 2026년 설문 시스템 개선 — 새 URL로 응답 부탁드립니다.

기존 설문 대신 아래 새 URL을 사용해주세요.
  • 상반기 통합설문(S01): [URL]
  • 각 사업별 현장설문: [URL들]

변경 사항:
  - 소속 기관을 선택하는 문항이 추가되었습니다.
  - 현장설문에서 참여하신 회차/일정을 선택하는 문항이 추가되었습니다.
  - 소속 권역 문항은 삭제되었습니다(기관 선택으로 자동 확인).
```
