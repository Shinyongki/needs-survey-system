# 00. 설문 체계 변경 — 공통 변경사항 요약

> 작성일: 2026-04-22
> 프로젝트: 경상남도사회서비스원 노인맞춤돌봄서비스 설문·분석 시스템
> 목적: 병렬 작업 세션 간 공통 참조 문서
> 대상: 모든 세션(A·B·C·D·E) 공통 선수 자료

---

## 📌 이 문서의 역할

이 프로젝트에서는 설문 체계의 전면적 변경이 결정되었다.
변경 작업은 규모가 커서 5개 세션으로 분할 병렬 진행한다.
**모든 세션은 이 문서를 먼저 읽은 후 본인 세션 문서로 진입해야 한다.**

---

## 🎯 변경 배경

**기존 체계의 한계**
- 기관명 미수집 → 어느 기관이 응답했는지 파악 불가
- 응답률 관리 불가, 미응답 기관 독려 불가
- 기관별 특성 비교 분석 불가
- 결과보고서에 기관별 인사이트 반영 불가

**변경 방향**
- 전 설문 17종에 기관명 문항 추가
- 분석 단위에 "기관별" 추가 (광역 내부용)
- 현장설문에 회차 식별 문항 추가
- 권역 문항 삭제 (기관 마스터에서 자동 도출)

## 📊 결과보고서 V장 통합설문 연동 원칙 (공식)

**원칙**:
> 현장설문 결과보고서의 통합설문 연동 분석은 **결과보고서 작성 시점 직전에 실시된 통합설문**(당해 상반기 또는 전년도 하반기)을 기준으로 한다. 당해 하반기 통합설문은 결과보고서 작성 시점에 아직 미실시될 수 있으므로 활용하지 않는다.

**활용 가능 통합설문**

| 결과보고서 작성 시점 | 활용 통합설문 |
|---------------------|---------------|
| 당해 1~3월 | 전년도 하반기 통합설문 |
| 당해 4월 이후~연말 | 전년도 하반기 + 당해 상반기 |

**연 1회 사업(J16·J17) 분석 비중 조정**
- III장(만족도): 간략 기술 (5점 척도 평균만)
- V장(통합설문 연동): 핵심 분석 — 상반기 통합설문 + 전년도 하반기 통합설문과 교차 분석
- VI장(이행 확인): 전년도 욕구 반영 여부 상세 확인
- 근거 문장 형식: `"현장설문 만족도 ○○점 / 통합설문 ○○% 요청 → 종합적으로 ○○ 개선"`

## 🗄 기관 마스터 데이터 구조

**기관 마스터 테이블 권장 구조**

```
institutions 테이블
├ id (PK, AUTO_INCREMENT)
├ institution_code (VARCHAR, UNIQUE) — 예: A48310001
├ institution_name (VARCHAR) — 예: 거제노인통합지원센터
├ sigungu (VARCHAR) — 예: 거제시
├ region (VARCHAR) — 예: 동부
├ active (BOOLEAN, DEFAULT TRUE)
```
