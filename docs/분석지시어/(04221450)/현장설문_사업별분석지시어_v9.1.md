## 공통 보고서 구조 (v8)

> 모든 사업의 결과보고서는 아래 9장 구조를 따릅니다.
> 각 사업의 **고유 분석 관점**이 II장에 명시되며, III~IX장의 모든 해석은 그 관점에서 서술합니다.

| 장 | 명칭 | 내용 | 활용처 |
|---|---|---|---|
| I | 조사 개요 | 사업명·응답대상·조사방법·응답인원·척도 | 보고서 기본 정보 |
| II | **이 사업의 분석 관점** | 광역의 역할, 문항 간 논리적 흐름, 핵심 질문 | 보고서 전체 해석의 렌즈 |
| III | 만족도 분석 | 문항별 응답 분포표 + **서술식** + 시각화(긍정비율 막대, 레이더) | 결과보고서 만족도 파트 (담당자 복사) |
| IV | **고유 분석** | 사업별 경로·패턴에 따른 심층 분석 (갭·교차·경로별) | 추진방향 도출 근거 |
| V | 주관식 분석 | 키워드 Top + 사업 고유 분류 체계 적용 | 현장 수요 파악 |
| VI | **통합설문 이행 확인** | 통합설문 욕구의 이행 판정 (개선/미개선) | 성과 환류 |
| VII | **이번 회차 개선 과제** | 만족도 약점 + 주관식에서 도출한 사후 환류 과제 | 다음 회차 개선 반영 |
| VIII | 요약 | 핵심 포인트 정리 박스 | 빠른 검토 |
| IX | 근거문장 | 형식 A·B·C + 이행 확인 근거 + 사후 환류 근거 | 계획서·결과보고서 직접 복사 |

> **서술식 원칙:** 개조식이 아닌 완결된 문장, 주어·동사·수치 포함, 사업담당자가 복사해서 사용 가능
> **근거문장 괄호:** 문항번호 대신 한글 직접 인용 (예: "(종합 만족도, 응대 신속성)")
> **이행 확인 ≠ 욕구 수집:** 통합설문에서 파악된 욕구의 이행 여부를 점검하는 것이지, 새 욕구를 수집하는 것이 아님
> **개선 과제 ≠ 추진방향:** 이번 결과에서 드러난 문제를 다음 회차에 반영하는 사후 환류이며, 연간 사업 방향은 통합설문 욕구에 따름

## 분석 단위 원칙 (v9 신규)

**분석 단위**: 전체 · 권역별 · 연령대별 · 경력별 · **기관별** (v9 신규) · **회차별** (선택, J16·J17 제외)

- 기관별 분석 결과는 광역지원기관 내부용으로만 활용. 수행기관 비공개.
- 권역별 분석은 responses 테이블의 institution_code를 institutions 마스터 테이블과 JOIN하여 region을 도출한 후 집계. 기관 마스터가 업데이트되면 과거 응답도 최신 권역 기준으로 자동 재집계됨.
- 도입-0 (소속 기관, 드롭다운 59개)은 v9 신규 도입 문항. 기관 마스터 institution_code와 연결.
- 도입-3 (소속 권역)은 삭제. 기관 마스터 JOIN으로 대체.

## 회차별 분리 분석 옵션 (v9 신규, J16·J17 제외)

> 현장설문은 한 폼에 여러 회차 응답이 누적된다.
> 운영자 판단에 따라 통합 분석 또는 회차별 분리 분석을 선택할 수 있다.

### 통합 분석 (기본)
- 모든 회차 응답 합산
- 기존 분석지시어 그대로 사용
- 연간 결과보고서 또는 총괄 분석 시 사용

### 회차별 분리 분석 (선택)
- 도입-0-a(회차 드롭다운) 값으로 필터링 후 동일 분석 반복
- 각 회차별 결과보고서 작성 시 사용

### 회차별 분리 분석 지시어 템플릿

```
[J코드]_[사업명].csv 데이터 중 [도입-0-a="○○회차_일자"]로 필터링하여
기존 분석을 동일하게 실시해줘.

필터 조건 예시:
- J03: 도입-0-a="1차 (2026-05-15)"
- J07: 도입-0-a="북부권역 (거창·함양·합천·산청) - 2026-06-15"
- J01: 도입-0-a="2026년 상반기 점검 (2026-04~06)"
```

### 회차별 결과보고서 작성 원칙
- 기본: 각 회차 종료 직후 회차별 결과보고서 작성
- 예외: 회차가 적거나 응답이 소규모인 사업은 연 통합 결과보고서로 작성 가능
- 회차별 vs 통합 선택 기준
  - 권역별 운영(J07 등): 권역별 결과보고서
  - 회차별 주제가 다른 교육(J03 등): 회차별 결과보고서
  - 상시·집합 운영(J08·J09·J11 등): 월/분기 또는 연 통합

## VI장(통합설문 이행 확인) 원칙 (v9 명시)

> 현장설문 결과보고서의 VI장(통합설문 이행 확인)에서 활용 가능한 통합설문은
> 결과보고서 작성 시점 직전에 실시된 것으로 한정한다.

| 결과보고서 작성 시점 | 활용 가능 통합설문 |
|---------------------|---------------------|
| 당해 1~3월 | 전년도 하반기 통합설문 |
| 당해 4월~연말 | 전년도 하반기 + 당해 상반기 |

**당해 하반기 통합설문은 결과보고서 작성 시점(연중)에 아직 미실시될 수 있으므로 활용하지 않음.**

### 연 1회 사업(J16·J17) 분석 비중 조정
- III장(만족도): 간략 기술 (5점 척도 평균만)
- VI장(통합설문 이행 확인): **핵심 분석** — 상반기 통합설문 + 전년도 하반기 통합설문 교차
- VII장(이행 확인): 전년도 욕구 반영 여부 상세 확인
- 근거 문장 형식: `"현장설문 만족도 ○○점 / 통합설문 ○○% 요청 → 종합적으로 ○○ 개선"`

## J01. 수행기관 모니터링·점검 (v9 상·하반기 분리)

> 패턴: **프로세스 4단계 평가형**
> 특화 문항: A-1(항목반영) · A-2(피드백구체) · A-3(개선방향파악) · A-4(방식적합) · A-5(주관식)

> ※ 도입-0-a 회차 드롭다운 선택지:
>   - `2026년 상반기 점검 (2026-04~06)`
>   - `2026년 하반기 점검 (2026-10~12)`

```
■ 고유 분석 관점

이 사업의 핵심 질문: "점검의 4단계가 순서대로 작동하는가, 어디서 끊어지는가"

광역의 모니터링·점검은 사전 안내 → 현장 파악 → 피드백 제공 → 개선 방향 도출 → 적합한 방식 운영이라는
프로세스로 진행된다. 4개 특화 문항은 이 프로세스의 각 단계를 측정한다.

경로: 공통-1(사전안내) → A-1(항목반영) → A-2(피드백구체) → A-3(개선방향파악) → A-4(방식적합) → 공통-3(운영개선도움)

분석 시 "각 단계의 점수가 순차적으로 유지되는가, 어느 단계에서 떨어지는가"를 확인한다.
예를 들어 사전 안내(공통-1)와 항목 반영(A-1)은 높은데 피드백(A-2)이 낮으면
"점검 내용은 좋지만 피드백이 구체적이지 않다"는 단절이 발생한 것이다.

■ 고유 분석 지시 (IV장)
① 4단계 프로세스 순차 분석: 공통-1→A-1→A-2→A-3→A-4→공통-3 각 평균을 순서대로 나열
   어느 단계에서 점수가 떨어지는지 "단절 지점" 특정
② 단절 지점 해석: 떨어진 단계의 의미와 원인 추정
③ A-4(방식적합)와 통합설문 A-1(점검방식선호) 연동:
   현장설문에서 방식 만족도가 낮으면 통합설문 선호 방식과 비교하여 미스매치 확인
④ 시각화: 프로세스 흐름 차트 (단계별 평균 꺾은선 + 단절 지점 표시)

■ 통합설문 연동 (VI장)
- 지적사항 개선 여부: 통합설문에서 미개선 ○○% → 현장설문 피드백 구체성(A-2)과 연결
- 점검 후 개선 지원 필요도: 통합설문에서 ○○% 필요 → 현장설문 개선방향파악(A-3)과 연결
- 점검 중점 항목: 통합설문 1순위 vs 현장설문 항목반영(A-1) 만족도

■ 주관식 분류 (V장)
A-5 키워드를 4가지 유형으로 분류:
- 점검 내용 관련 (항목·기준·반영)
- 사후 지원 관련 (컨설팅·안내·자료)
- 운영 방식 관련 (방문·서면·화상·일정)
- 긍정 표현 (감사·도움)

```
■ 고유 분석 관점

역량강화교육은 운영 편의(접근성·시간대·방식)와 교육 효과(현장 적용 가능성) 두 요소로 평가된다.
종사자가 교육에 만족하더라도 배운 내용을 현장에 적용하지 못하면 교육의 실효성이 없다.

- 운영편리 > 현장적용 → "참여하기는 좋았는데 현장에 쓸 수 없다" → 내용 실무 밀착도 강화
- 운영편리 < 현장적용 → "내용은 좋았는데 참여가 불편했다" → 운영 방식(시간·장소) 개선

■ 고유 분석 지시 (IV장)
① 2요소 갭 분석: B1-1 vs B1-2 평균·긍정비율 비교
② 공통-1(주제적합) → B1-2(현장적용) 연결: 주제가 적합해야 적용 가능한가
③ 공통-2(강사전문성) → B1-2(현장적용) 연결: 강사가 좋아야 적용 가능한가
④ 통합설문 역량부족 영역 1순위와 이번 교육 주제 일치 여부 확인

■ 통합설문 연동 (VI장)
- 교육 미참여 사유 1순위(업무공백 ○○%) → 현장설문 B1-1(운영편리) 만족도와 연결
- 역량부족 영역 vs 교육수요 3가지 패턴(일치/인식갭/선제수요)과 이번 교육 주제 대조
- 교육 방식 선호 1순위와 이번 교육 방식 일치 여부

■ 주관식 분류 (V장)
B1-3 키워드를 4가지 유형으로:
- 교육 내용 관련 (주제·실습·사례·이론)
- 강사 관련 (전문성·전달방식)
- 운영 방식 관련 (시간대·장소·온라인·집합)
- 내년 요청 (확대·추가·신규 주제)

■ 고유 분석 관점

이 사업의 핵심 질문: "교육 만족은 높은데 실제 소진이 회복되는가 — 만족과 효과의 괴리"
