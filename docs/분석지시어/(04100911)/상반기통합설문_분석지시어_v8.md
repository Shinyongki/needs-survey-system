## 기타 응답 처리 안내

> ※ 구글폼에서 "기타 (직접 입력)"을 선택한 응답은 숫자 코드가 아닌 **자유 텍스트**로 CSV에 저장됩니다.

| 문항 유형 | CSV 저장 방식 | 처리 방법 |
|---|---|---|
| 단일선택 | 기타 선택 시 입력 텍스트 그대로 저장 | 숫자 코드 외 값 = 기타로 분류 |
| 복수선택 | `1;3;직접입력내용` (숫자+텍스트 혼재) | 세미콜론 파싱 후 숫자 항목·텍스트 항목 분리 |

**기타 처리 기본 원칙:**
- 기타 응답이 **5% 이상**이면 내용 요약 필수
- 기타 응답이 **3건 이상**이면 반복 키워드 추출
- 기타 내용에 새 카테고리가 보이면 별도 표시 — 다음 연도 선택지 보완 근거로 활용

## 유형 1. 현황분석 집계

```
상반기 통합설문 데이터로 현황분석 25개 문항을 집계해줘.
각 문항별로 응답 분포(빈도·비율)를 표로 정리하고,
핵심 수치(가장 높은 응답, 누적 비율 등)를 1~2줄로 해석해줘.
경고가 필요한 문항(부정 응답이 높은 항목)은 ⚠️ 표시해줘.

기타 응답 처리:
기타가 포함된 문항(현공-2_어려운영역, 현B전담-1_미참여이유, 현B1-1_역량부족영역)은
숫자 코드 외 텍스트 응답을 별도 집계하고,
기타 비율과 주요 내용을 표에 함께 표시해줘.
기타 비율이 5% 이상이면 ⚠️ 표시하고 내용을 1~2줄로 요약해줘.

현황분석 문항 목록 (25개):
현공-1_전년도만족도, 현공-2_어려운영역, 현공-3_업무량적절성,
현A-1_지적사항개선,
현C-1_협의회도움, 현C-2_실무협의회필요도,
현D1-1_컨설팅이용,
현D2-1_특화대상자수, 현D2-2_위기사례경험,
현D3-1_협력체계원활,
현D4-1_노무어려움,
현B전담-1_미참여이유, 현B1-1_역량부족영역(복수),
현B3-1_소진경험, 현B3-2_폭언경험,
현E1-1_게이트웨이어려움, 현E1-2_돌봄로봇어려움,
현E2-1_나눔참여여부, 현E2-2_집결어려움,
현E3-1_서비스인지,
현F2-1_유공자추천, 현F2-2_최근3년추천경험, 현F2-3_자체포상유무,
현F3-1_사전안내충분, 현F3-2_소진예방활동비

시각화:
집계 완료 후 아래 차트를 함께 생성해줘.
① 현공-3_업무량적절성 — 5점 척도 세로 막대차트
② 현B3-1_소진경험 — 도넛 차트
③ ⚠️ 표시된 문항들의 부정 응답 비율만 모아서 — 수평 막대차트 (높은 순 정렬)
   제목: "주의 필요 항목 — 부정 응답 비율 비교"
```

## 유형 2. 섹션별 욕구 우선순위

```
상반기 통합설문 데이터로 섹션별 욕구 우선순위를 분석해줘.
단일선택 문항은 1순위 응답과 비율을,
복수선택 문항(세미콜론 구분)은 파싱해서 항목별 빈도 Top 3를 뽑아줘.
섹션 순서: A → C → D1 → D2 → D3 → D4 → B1 → B3 → E1 → E2 → E3 → F2 → F3
결과는 섹션별로 구분해서 표로 정리해줘.

기타 응답 처리:
- 단일선택 문항: 숫자 코드가 아닌 텍스트 응답은 '기타'로 집계하고 주요 내용을 요약해줘.
- 복수선택 문항: 세미콜론(;) 파싱 시 숫자가 아닌 항목을 '기타' 텍스트로 분류하고
  3건 이상이면 반복 키워드를 추출해줘.
- 기타가 1순위 또는 상위권이면 해당 문항의 선택지 보완 필요 신호로 해석해줘.

시각화:
① 복수선택 문항(B1-1, C-1, A-2) — 각각 수평 막대차트 (빈도순 정렬, 선택지 텍스트 표시)
② 단일선택 욕구 문항 중 1순위 항목만 모아 — 13개 섹션 1순위 요약 수평 막대차트
   제목: "섹션별 욕구 1순위 항목 비교"
```

## 유형 3. 교차분석

### 3-1. 경력별

```
상반기 통합설문 데이터로 경력별 교차분석을 해줘.
교차변수: 기본-1_경력 (1=1년미만, 2=1~3년, 3=3~5년, 4=5년이상)
분석 문항:
- 현B3-1_소진경험 (1=자주, 2=가끔, 3=거의없음, 4=전혀없음)
- 현B1-1_역량부족영역(복수) → 항목별 언급 비율
- B1-2_교육방식선호 (단일선택)
- 현공-3_업무량적절성

경력 집단별로 응답 분포를 비교하고,
집단 간 차이가 두드러진 항목은 별도로 해석해줘.

시각화:
① 경력별 × 소진경험 — 누적 가로 막대차트 (경력 4집단, 소진 4응답)
② 경력별 × 업무량적절성 — 그룹 세로 막대차트
③ 경력별 역량부족영역 — 히트맵 또는 그룹 막대 (경력 4집단 × 영역 6항목)
```

### 3-2. 권역별

```
상반기 통합설문 데이터로 권역별 교차분석을 해줘.
교차변수: 기본-2_권역 (1=북부, 2=서부, 3=중부, 4=동부)
권역 구성:
  북부: 거창·함양·합천·산청 / 서부: 진주·사천·고성·남해·하동
  중부: 창원·함안·의령·창녕 / 동부: 김해·양산·밀양·통영·거제

분석 문항:
- 현공-3_업무량적절성
- 현B3-1_소진경험
- 현D2-2_위기사례경험
- 현E1-1_게이트웨이어려움

권역별로 응답 분포를 비교하고,
특정 권역에서 집중 지원이 필요한 항목을 짚어줘.
지원 방식 권역 차등화가 필요한 근거도 제시해줘.

시각화:
① 권역별 4개 문항 부정 응답 비율 — 그룹 막대차트 (권역 4개 × 문항 4개)
② 권역별 종합 부정 지표 — 레이더 차트 (4개 축 = 4개 문항, 4개 권역 겹침)
```

### 3-3. 연령대별

```
상반기 통합설문 데이터로 연령대별 교차분석을 해줘.
교차변수: 기본-0_연령대 (1=20대, 2=30대, 3=40대, 4=50대, 5=60대이상)
분석 문항:
- 현B전담-1_미참여이유 (교육 미참여 이유)
- 현B3-1_소진경험
- B1-2_교육방식선호 (집합·권역·온라인·자기주도·신규경력분리)
- 현E1-1_게이트웨이어려움

연령대별 응답 분포를 비교하고,
연령 집단 특성에 맞는 교육 방식·지원 방향을 제안해줘.

시각화:
① 연령대별 × 교육방식선호 — 누적 가로 막대차트
② 연령대별 × 소진경험 — 그룹 세로 막대차트
```

## 유형 4. 사업 운영 근거문장 생성

```
상반기 통합설문 현황분석 + 욕구조사 결과를 바탕으로
각 사업별 사업 운영 근거문장을 만들어줘.

근거문장 3가지 형식:
형식 A (현황 기반): "상반기 조사 결과 ○○%가 ○○하여 ○○을 추진한다."
형식 B (욕구 기반): "상반기 조사 결과 ○○%가 ○○을 요청하여 ○○을 추진한다."
형식 C (현황+욕구 연결): "상반기 조사 결과 ○○%가 ○○ 상태이며, ○○%가 ○○을 요청하여 ○○ 방향으로 추진한다."

대상 사업 및 활용 문항 (현황+욕구 모두 활용):
- 수행기관 모니터링·점검: 현A-1 + A-1·A-2·A-3
- 실무협의회: 현C-1·현C-2 + C-1·C-2·C-3·C-4
- 컨설팅 지원: 현D1-1 + D1-1·D1-2
- 역량강화교육: 현B전담-1·현B1-1 + B1-1·B1-2
- 심리지원교육: 현B3-1·현B3-2 + B3-1·B3-2
- 특화지원서비스: 현D2-1·현D2-2 + D2-1
- 퇴원환자 단기집중: 현D3-1 + D3-1·D3-2
- 노무 상담 지원: 현D4-1 + D4-1·D4-2
- ICT 지원: 현E1-1·현E1-2 + E1-1
- 나눔사업: 현E2-1·현E2-2 + E2-1
- 안심 돌봄 캠페인: 현E3-1 + E3-1·E3-2
- 유공자 표창: 현F2-1·현F2-2·현F2-3 + F2-1·F2-2
- 종사자 지원사업: 현F3-1·현F3-2 + F3-1
- 종사자 안전 지원: 현B3-2 (B3 섹션 연동)

각 사업별로 형식 C를 우선 사용하고,
실제 수치를 반드시 포함하며 근거 문항 번호를 괄호로 병기해줘.
```

## 유형 6. 섹션별 통합 인사이트 분석

> **v8 확정 구조:** 전 13개 섹션에 동일한 6단계 구조를 적용합니다.
>
> | 단계 | 구성 요소 | 내용 | 활용처 |
> |---|---|---|---|
> | ① | **현황분석 표 + 서술식** | 응답 분포표 + "현재 상태가 이렇다" 서술 문장 | 사업계획·결과보고서 현황분석 파트 (담당자 복사 사용) |
> | ② | **욕구조사 표 + 서술식** | 응답 분포표 + "현장은 이것을 원한다" 서술 문장 | 사업계획 욕구조사 파트 (담당자 복사 사용) |
> | ③ | **시각화** | ①②의 차트 | 보고서 삽입용 |
> | ④ | **현황↔욕구 연결 해석** | "현황이 이런데 욕구가 이렇다, 그래서 이렇게 해야 한다" | 추진방향 도출 근거 |
> | ⑤ | **요약 박스** | ①~④의 핵심 포인트 정리 | 빠른 검토용 |
> | ⑥ | **근거문장** | 형식 A·B·C 계획안 인용 문장 | 사업계획서에 직접 복사 |
>
> **서술식 작성 원칙:**
> - 개조식이 아닌 완결된 문장으로 작성 (사업담당자가 계획안에 그대로 복사 가능)
> - 주어·동사·수치를 포함한 3~5개 문장
> - 핵심 수치는 반드시 포함 (빈도·비율)
> - "해당 없음" 등 제외 대상이 있는 문항은 분모를 명시하여 재산출
>
> **근거문장 괄호 표기:** 문항번호 대신 한글 직접 인용
> - (지적사항 개선 여부, 점검 중점 항목) ← "현A-1, A-2" 대신
> - (소진 경험, 소진 상황, 심리지원 프로그램 선호) ← "현B3-1, B3-1, B3-2" 대신
