#### J05 심리지원교육 — 전담사회복지사

**현재 핵심 구조 표현:**
```
> 핵심 구조: 운영편리(B3-1) · 감정노동도움(B3-2) · 현장적용(B3-3)
```
**수정 후:**
```
> 핵심 구조: 운영편리(B3-1) · 감정노동도움(B3-2) · 심리부담완화(B3-3)
```

**M1 기술통계 분析 지시어 — B3-3 참조 문구 수정:**
```
# 수정 전
공통 4문항과 특화 척도 3문항(B3-1·B3-2·B3-3) 포함.
# 수정 후 (동일, 번호 유지)
공통 4문항과 특화 척도 3문항(B3-1·B3-2·B3-3) 포함.
→ B3-3은 "심리적 부담감 완화 여부" 문항
```

**M2 3요소 균형 분析 지시어 — B3-3 해석 수정:**
```
# 수정 전
B3-3(현장적용가능) 점수와 연결: 배운 내용이 실제 적용 가능한가
# 수정 후
B3-3(심리부담완화) 점수: 교육 후 심리적 부담감이 실제로 줄었는가
→ B3-3이 낮다면: "교육 참여는 했으나 심리 회복 효과 미흡 → 프로그램 설계 재검토 필요"
```
