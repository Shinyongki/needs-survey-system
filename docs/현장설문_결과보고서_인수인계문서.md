## 1. 프로젝트 컨텍스트

### 조직 구조
- **(재)경상남도사회서비스원** 광역지원기관
- 노인맞춤돌봄서비스 — 59개 수행기관 (18개 시군구, 4개 권역)
- 광역지원기관의 역할: 수행기관에 교육·컨설팅·점검·지원사업 운영

### 설문 체계
- **상반기 통합설문(S01)**: 60문항, 4월, 전담사회복지사 전원 → 현황분석+욕구조사
- **하반기 통합설문(S02)**: 63문항, 11~12월 → 올해 결과 평가+내년 계획 수립
- **현장설문 15종**: 각 사업 종료 직후, 만족도·경험 평가 → 결과보고서

### 핵심 규칙
- **"경영평가" 용어 사용 금지** → "사업 운영 근거 확보" 사용
- **析 한자 금지** → "분석" 한글만 사용
- **영어 약자 금지** → 한글 전체 표기 (SW→전담사회복지사, IPA→중요도-만족도 분석)
- **문항번호 괄호 금지** → 한글 직접 인용 ("(종합 만족도, 응대 신속성)" ← "(공통-4, 공통-2)" 대신)
- **근거문장 형식**: "○○조사 결과 ○○%가 ○○을 요청하여 ○○을 추진한다."

## 2. 확정된 보고서 구조 (9장)

모든 현장설문 결과보고서는 아래 9장 구조를 따릅니다.

| 장 | 명칭 | 내용 | 핵심 포인트 |
|---|---|---|---|
| I | 조사 개요 | 사업명·응답대상·방법·인원·척도 | 표 형태 |
| II | **이 사업의 분석 관점** | 광역의 역할, 문항 간 경로 구조, 핵심 질문 | **사업마다 다른 내용** — 아래 총괄표 참조 |
| III | 만족도 분석 | 문항별 분포표 + **서술식** + 시각화(긍정비율 막대, 레이더) | 서술식은 담당자 복사 활용 가능한 완결 문장 |
| IV | **고유 분석** | 사업별 경로·패턴에 따른 심층 분석 (갭·교차·경로별) | **사업마다 다른 분석 방법** |
| V | 주관식 분석 | 키워드 Top + 사업 고유 분류 체계 | 유형별 분류 (사업마다 다른 분류 기준) |
| VI | **통합설문 이행 확인** | 통합설문 욕구의 이행 판정 (개선/미개선) | 새 욕구 수집이 아닌 이행 점검 |
| VII | **이번 회차 개선 과제** | 만족도 약점 + 주관식에서 도출한 사후 환류 과제 | 하단에 "연간 방향은 통합설문에 따름" 명시 |
| VIII | 요약 | 핵심 포인트 정리 박스 | 파란 테두리 박스 |
| IX | 근거문장 | 만족도+고유분석+이행확인+사후환류 기반 4~5개 | 한글 직접 인용 괄호 |

### 서술식 작성 원칙
- 개조식이 아닌 **완결된 문장** (주어·동사·수치 포함)
- 사업담당자가 결과보고서에 **그대로 복사**해서 쓸 수 있는 수준
- 3~5개 문장으로 구성

### 시각화 원칙
- III장: 긍정비율 수평 막대 + 레이더(균형 프로파일) — 필수
- IV장: 사업 고유 분석에 맞는 차트 (갭 비교, 교차 분석, 경로 구조도 등)
- V장: 키워드 분류별 수평 막대
- 차트는 matplotlib로 생성 → docx에 ImageRun으로 삽입

### 욕구 체계 정합성
- **통합설문 보고서**: "추진방향 및 근거문장" — 사전 계획 (욕구 기반)
- **현장설문 보고서**: "이번 회차 개선 과제" — **사후 환류** (결과 기반)
- **현장설문 보고서**: "통합설문 이행 확인" — **이행 점검** (개선/미개선 판정)
- 현장설문에서 새 욕구를 수집하는 것이 아님 → 구조적 충돌 없음

## 6. 각 세션에서 따라야 할 작업 절차

```
각 사업별로 아래 순서로 진행합니다.

1단계: mock 데이터 생성 (Python)
  - CSV 파일 생성 (도입부 3 + 공통 4 + 특화 문항)
  - 사업 특성에 맞는 데이터 분포 설정
    (예: J05 심리지원은 소진 회복 점수를 의도적으로 만족도보다 낮게)
  - 주관식 응답 풀 생성 (사업 고유 키워드 포함)

2단계: 데이터 분석 (Python)
  - 문항별 빈도·비율·평균·긍정비율·부정비율
  - 사업 고유 교차 분석 (갭, 경로별, 조건부)
  - 주관식 키워드 추출 및 분류
  - 통합설문 연동 수치 참조 (아래 7절 참조)

3단계: 차트 생성 (matplotlib)
  - 긍정비율 수평 막대 (필수)
  - 레이더 균형 프로파일 (필수)
  - 고유 분석 차트 (갭·교차·경로 등)
  - 주관식 키워드 분류 막대
  - 통합설문 연동 비교 차트

4단계: docx 생성 (Node.js docx 라이브러리)
  - 9장 구조 적용
  - 차트 이미지 삽입 (ImageRun, type:"png" 필수)
  - 서술식·요약 박스·근거문장 포함
  - outputs 폴더로 복사

5단계: 검증
  - validate.py 통과 확인
  - present_files로 사용자에게 전달
```
