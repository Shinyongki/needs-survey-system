# 통합설문 분석결과보고서 docx 생성 가이드

> 목적: 상반기·하반기 통합설문 분석결과보고서를 일관된 품질로 생성하기 위한 구현 명세
> 적용 대상: 상반기 통합설문(S01, 60문항) / 하반기 통합설문(S02, 63문항)
> 기준 문서: 상반기통합설문_분석지시어_v8.md / 하반기통합설문_분석지시어_v8.md
> 디자인 기준: 현장설문 결과보고서 docx 생성 가이드 v3 (동일 디자인 시스템 적용)
> 작성일: 2026-04-10

---

## 1. 핵심 원칙

- 이 가이드는 **분석지시어 v8(설계)**와 **docx 출력(구현)** 사이의 간극을 없애기 위한 문서이다
- 분석지시어의 유형 1~9를 문서 장 구조에 빠짐없이 매핑한다
- 13개 섹션별 통합 인사이트(유형 6)는 6단계 구조를 모두 반영한다
- 서술식 문장은 개조식이 아닌 완결 문장이며, 사업담당자가 계획안·결과보고서에 그대로 복사 가능해야 한다
- 현장설문 결과보고서와 동일한 디자인 시스템(색상·박스·차트 규격)을 사용하여 시각적 일관성을 유지한다

#### 6단계 구조 상세 (각 섹션 공통)

**① 현황분석 표 + 서술식**

필수 구성물:
- **응답 분포(빈도·비율) 표**: 해당 현황 문항별로 선택지·빈도·비율 표를 반드시 삽입한다
- **분모 재산출**: "해당 없음", "경험 없음", "참여하지 못함" 등이 있는 문항은 해당 응답을 제외한 분모를 명시하고 비율을 재산출한다. 예: "지적사항이 있었던 140명 중(전체 187명에서 '지적 없었음' 47명 제외)"
- **판정 행 표시**: 양호/보통/주의를 표의 컬럼 또는 행 색상으로 구분한다
- **서술식 문장 3~5개**: 주어·동사·수치를 포함한 완결된 문장. 사업담당자가 결과보고서에 그대로 복사 가능한 수준이어야 한다

```
[표 예시]
| 선택지 | 빈도 | 비율 | 비고 |
|---|---|---|---|
| ① 지적사항 없었음 | 47명 | 25.1% | 분모 재산출 시 제외 |
| ② 완전 개선 | 19명 | 10.2% | — |
| ③ 대부분 개선 | 56명 | 29.9% | — |
| ④ 일부 개선 | 37명 | 19.8% | — |
| ⑤ 미개선 | 28명 | 15.0% | ⚠️ |
| **재산출 (지적 있었던 140명 기준)** | — | — | 개선율: 80.0% / 미개선: 20.0% |
```

**② 욕구조사 표 + 서술식**

필수 구성물:
- **단일선택 문항별 응답 분포(빈도·비율) 표**: 모든 욕구 문항에 대해 삽입
- **복수선택 문항 빈도표**: 세미콜론 파싱 → 항목별 빈도·비율 표 (빈도순 정렬), 선택지 코드→텍스트 변환 필수
- **주관식 키워드 분석**: 해당 섹션에 주관식 문항이 있으면 키워드 Top 5 표를 반드시 작성한다 (긍정/개선요구 분류)
- **기타 응답 처리**: 기타 5% 이상이면 내용 요약 필수, 3건 이상이면 반복 키워드 추출
- **서술식 문장 3~5개**

```
[주관식 키워드 표 예시]
| 순위 | 키워드 | 건수 | 분류 |
|---|---|---|---|
| 1 | 사례 중심 교육 | 12건 | 교육 내용 |
| 2 | 온라인 확대 | 9건 | 운영 방식 |
| 3 | 교육 시간 단축 | 7건 | 운영 방식 |
| 4 | 선배 멘토링 | 5건 | 교육 내용 |
| 5 | 매뉴얼 배포 | 4건 | 자료 지원 |
```

**③ 시각화**

- 섹션당 **최소 2개, 최대 4개** 차트 (분석지시어 유형 6의 각 섹션별 지시에 따름)

- 대응 비교 차트가 지정된 섹션은 반드시 포함 (예: B1의 역량부족↔교육수요, A의 어려운영역↔점검중점)

**② 이행 해석 서술** (3~5문장)
- "상반기에 문제였던 항목 → 올해 사업 운영 → 하반기에 개선되었는가" 경로 확인
- 개선 항목: 성과로 기록
- 미개선 항목: 내년도 재설계 근거

## 7. 데이터 준비

### 7-1. CSV 파일 구조

```
┌─ 실제 데이터 ─────────────────────────────────────────────┐
│ ① 구글폼 CSV 내보내기                                      │
│ ② CSV 헤더:                                                │
│    - 지시문 05 적용 전: 한글 질문 전체 텍스트 → 열 매핑 필요│
│    - 지시문 05 적용 후: Q번호 헤더 → 직접 사용 가능        │
│ ③ 권역 응답: "중부(창원·함안·의령·창녕)" 전체 텍스트       │
│    → 앞 2글자로 권역 추출                                   │
│ ④ 기타 응답:                                               │
│    - 단일선택: 숫자 코드 외 텍스트 = 기타 분류             │
│    - 복수선택: 세미콜론(;) 파싱 후 숫자·텍스트 분리         │
└───────────────────────────────────────────────────────────┘
```

### 7-2. 기타 응답 처리 원칙

| 조건 | 처리 |
|---|---|
| 기타 5% 이상 | 내용 요약 필수 |
| 기타 3건 이상 | 반복 키워드 추출 |
| 기타가 1순위 | 선택지 보완 필요 신호로 해석 |
| 기타에 새 카테고리 | 다음 연도 선택지 보완 근거 별도 표시 |

### 7-3. 조건부 문항 처리

| 문항 | 조건 | 처리 |
|---|---|---|
| B3-1 소진상황(복수) | B3-1에서 ③④(거의없음·전혀없음) 선택 시 건너뜀 | 소진 경험자(①②) 기준으로만 분석 |
| 분모 재산출 대상 | "해당 없음", "경험 없음", "참여하지 못함" | 해당 응답 제외 후 비율 재산출, 분모 명시 |

## 8. 분석 코드 필수 항목

### 8-0. 데이터 정합성 원칙 (절대 규칙)

**⚠️ 보고서에 기재되는 모든 수치는 분석 스크립트에서 실제 CSV 데이터를 기반으로 산출한 값이어야 한다.**

- **하드코딩 금지**: docx 생성 스크립트에서 "35.0%", "45.0%" 등 임의 수치를 직접 입력하지 않는다
- **산출 → 저장 → 참조 흐름**: 분석 스크립트가 CSV를 읽어 모든 수치를 JSON으로 저장하고, docx 생성 스크립트는 JSON에서만 수치를 참조한다
- **JSON 구조**: 13개 섹션별로 다음을 반드시 포함한다
  - 현황 문항별 빈도·비율 분포 (선택지 코드→텍스트 변환 완료)
  - 욕구 문항별 빈도·비율 분포
  - 복수선택 문항 파싱 결과 (항목별 빈도·비율)
  - 분모 재산출 결과 (원래 분모, 제외 인원, 재산출 분모)
  - 주관식 키워드 Top 5 (건수·분류)
  - 핵심 지표 (미충족률, 경험률, 부정률 등)
  - 교차 참조 분석 결과

### 8-1. 기본 분석

| 분석 | 산출 항목 |
|---|---|
| 기술통계 | 문항별 빈도·비율·평균(해당 시)·긍정비율·부정비율 |
| 판정 | 양호/보통/주의 자동 판정 |
| 복수선택 파싱 | 세미콜론 분리 → 항목별 빈도 집계 → 코드↔텍스트 변환 |
| 주관식 분석 | 키워드 추출, 주제 분류, Top 5~7 순위 |
| 교차분석 | 경력별·권역별·연령대별 응답 분포 비교 |

### 8-2. 섹션별 고유 분석

- 분모 재산출 (해당 없음 제외) — 각 섹션별 재산출 대상은 분석지시어 참조
- 현황↔욕구 교차 — IV장 ④단계에서 수행
- 교차 섹션 연결 — 타 섹션 문항과의 관계 분석

### 8-3. 하반기 추가 분석

- 상반기↔하반기 비교 (8개 문항 쌍)
- 현장설문 CSI 연동 (15개 사업 만족도 수치 상수로 포함)
- 교육 관련 수요 변화 (3개 문항 쌍)
