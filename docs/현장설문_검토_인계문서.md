# 현장설문 검토 인계 문서

> 작성일: 2026년 4월
> 목적: 상·하반기 통합설문 수정 내용이 현장설문에 미치는 영향 검토 및 수정 작업 인계
> 다음 세션에서 이 문서를 먼저 읽고 작업을 시작할 것

---

## 1. 배경 요약

경상남도사회서비스원(광역지원기관) 노인맞춤돌봄서비스 설문 체계를 정비하는 과정에서
상반기 통합설문(S01)과 하반기 통합설문(S02)에 대한 문항 수정 작업을 완료했다.
이 수정 내용 중 일부가 현장설문(J시리즈, 15종)과 내용적으로 연결되어 있어
현장설문에도 동일하게 반영하거나 검토해야 할 항목이 있다.

---

## 2. 완료된 작업

### 2-1. 상반기 통합설문(S01) 수정 완료 (56문항 → 60문항)

| 수정 항목 | 내용 |
|---|---|
| 현공-1 | 괄호 예시 추가 (교육, 실무협의회, 간담회, 워크숍 등) + ⑥ 해당 없음(신규 입사) 추가 |
| 섹션 C 제목 | 실무협의회 → 실무협의회(간담회, 정례회의 등) |
| C-1 ⑤ | 행정·서류 간소화 → 사업 지침·기준 현장 적용 논의 |
| C-3 ① | 현행 찾아가는 현장 방식 유지 → 수행기관 현장 방문 방식 |
| D1-1 ③ | 퇴원환자 서비스 실무 삭제 → 선택지 4개로 재번호 |
| 현D3-1 | 병원·지자체 → 지자체 / ④ 지자체 비협조로 수정 |
| D3-1 | ① 지자체 협력 체계 구축 / ⑥ 광역 주관 간담회 운영 신규 추가 |
| E3 섹션 | E3-2 홍보 물품 선택형 신규 추가 → 4문항 / 주관식 E3-3으로 재번호 |
| E3-3 주관식 | 캠페인 주제 포함 문구 확장 |
| F2 섹션 | 현F2-2(추천 이력)·현F2-3(포상 제도)·F2-2(행사 욕구) 신규 추가 → 5문항 |

## 3. 현장설문 검토 필요 항목

통합설문 수정 내용과 현장설문의 연결 지점을 분석한 결과,
아래 5개 J코드에서 검토 및 수정이 필요하다.

---

### 3-1. J07. 실무협의회

**연결 수정:** 섹션 C 제목 → `실무협의회(간담회, 정례회의 등)`

**검토 사항:**
- J07 설문 진입 안내문: "다음 문항은 이번 실무협의회에 관한 내용입니다."
  → "다음 문항은 이번 실무협의회(간담회, 정례회의 등)에 관한 내용입니다."로 수정 여부 검토
- 사업명 자체는 "실무협의회"로 유지하되, 신규 종사자 이해를 위한 예시 병기 여부 결정 필요

**현재 문항:** 변경 불필요 (문항 내용 자체는 영향 없음)

---

### 3-2. J08. 컨설팅 지원

**연결 수정:** 통합설문 D1-1에서 `③ 퇴원환자 서비스 실무` 삭제

**검토 사항:**
- 현재 J08 D1-1 선택지: ① 서비스 제공 실무 ② 행정·서류 처리 ③ 이용자 안전사고 대응 ④ 퇴원환자 서비스 실무 ⑤ 노무·인사 ⑥ 기타
- 통합설문에서는 퇴원환자 컨설팅을 제공할 전문가가 없어 삭제함
- **그러나 현장설문 D1-1은 "이번에 지원받은 컨설팅 분야"를 묻는 문항** (욕구가 아닌 경험)
- 실제로 퇴원환자 관련 컨설팅이 제공된 경우 응답해야 하므로 삭제 여부 별도 판단 필요
- **핵심 질문:** 광역이 퇴원환자 컨설팅을 아예 제공하지 않는다면 삭제, 일부 제공한다면 유지

---

### 3-3. J10. 퇴원환자 단기집중서비스

**연결 수정:** 통합설문에서 `병원·지자체` → `지자체`로 범위 축소

**현재 J10 D3-2 문항:**
> 광역의 지원을 통해 **병원·지자체**와의 협력 절차를 이해하고 적용할 수 있었습니까?

**검토 사항:**
- 통합설문 수정 이유: 병원 협력은 수행기관에 부담이 크다는 판단
- 현장설문 D3-2는 광역 지원을 통한 협력 절차 이해 여부를 묻는 문항
- 병원 협력이 퇴원환자 서비스의 핵심이므로 현장설문에서는 유지하는 것이 나을 수 있음
- **핵심 질문:** 현장설문에서도 `지자체`로만 좁힐 것인지, `병원·지자체` 표현을 유지할 것인지 결정 필요

---

### 3-4. J11. 노무 상담 지원

**연결 수정:** 통합설문 D4-1 ⑤ `폭언·폭행 피해 대응` → `폭언·폭행 피해의 산재·법적 절차 처리`

**현재 J11 D4-1 선택지 ⑤:**
> ⑤ 폭언·폭행 피해 대응

**검토 사항:**
- 통합설문과 동일하게 `폭언·폭행 피해의 산재·법적 절차 처리`로 수정하면
  상·하반기 욕구조사 결과와 현장설문 실제 이용 유형 간 비교 분석이 가능해짐
- 표현 일치 여부가 분석 연결성에 영향 → **수정 강력 권고**

---

### 3-5. J14. 안심 돌봄 캠페인

**연결 수정:** 통합설문 E3에 홍보 물품 선택형 문항 신규 추가 / 주관식 문구 확장

**현재 J14 구성:**
- E3-1: 캠페인 홍보물 도움 여부 (5점 척도)
- E3-2: 효과적 홍보 채널 (단일선택)
- E3-3: 주관식 (바라는 점)

**검토 사항:**
- 통합설문에서 "필요한 홍보 물품" 욕구를 수집하기 시작함
- J14 현장설문에서는 실제 사용한 홍보 물품의 효과를 측정하는 문항 추가 여부 검토
- 예시 추가 문항: "이번 캠페인에서 제공된 홍보 물품이 이용자 서비스 홍보에 도움이 되었습니까?" (5점 척도)
- 주관식 E3-3도 캠페인 주제 제안 포함으로 확장 여부 검토
- **핵심 질문:** 현장설문에서 물품 효과 측정 문항을 추가할 것인지 결정 필요
  (추가 시 문항 수 증가)

---

### 3-6. J16. 유공자 표창

**연결 수정:** 통합설문 F2에 아래 3개 문항 신규 추가
- 현F2-2: 최근 3년간 표창 추천 이력
- 현F2-3: 수행기관 자체 포상·인센티브 제도 운영 여부
- F2-2: 표창 외 자긍심 제고 행사 욕구

**현재 J16 구성:**
- F2-1: 공적조서 작성 가이드 도움 여부 (5점 척도)
- F2-2: 추천 경험이 향후 발굴·추천에 도움이 되겠는지 여부 (5점 척도)
- F2-3: 주관식 (바라는 점)

**검토 사항:**
- 통합설문에서 "표창 외 행사" 욕구를 수집하기 시작함
- J16 현장설문 주관식(F2-3)에 행사 주제 제안 내용을 추가하는 방향 검토
- 현재 F2-3: "표창 관련 광역에 바라는 점을 적어주세요."
  → "표창 관련 광역에 바라는 점 또는 종사자 자긍심 제고를 위해 추진했으면 하는 행사를 적어주세요."로 확장 검토
- **핵심 질문:** 주관식 문구 확장만 할 것인지, 별도 선택형 문항을 추가할 것인지 결정 필요
